KARAOKÊ PALCO · APP

Uma segunda forma de abrir o Palco — mesma tela de sempre, só que numa janela própria em vez de uma aba de navegador. A vantagem: quando um vídeo tem a incorporação bloqueada pelo YouTube, esse app volta sozinho pro Karaokê assim que a música termina, sem precisar clicar em nada.

Experimental — o site normal continua funcionando exatamente igual, esse app é só uma alternativa.

Funciona em qualquer Mac (Apple Silicon ou Intel).

Windows

Para PCs com Windows de 64 bits (a maioria).

Baixar para Windows .exe · v1.0.1

Instalar no Mac

  1. Abra o arquivo .dmg baixado.
  2. Arraste o ícone Karaokê Palco para a pasta Applications.
  3. Abra pelo Launchpad ou pela pasta Applications.
  4. Só na primeira vez: o Mac vai avisar que não conseguiu verificar o app (ele não tem assinatura paga da Apple). Se aparecer uma caixa com "Mover para o Lixo" / "OK", clique em OK (não mova pro lixo!). Depois:
    1. Abra Ajustes do Sistema → Privacidade e Segurança.
    2. Role até a seção de Segurança — vai ter um aviso sobre o Karaokê Palco ter sido bloqueado, com um botão "Abrir Assim Mesmo". Clique nele.
    3. Confirme com Touch ID/senha se pedir, e abra o app de novo.
    (Em versões mais antigas do macOS, às vezes clicar com o botão direito no ícone → "Abrir" já resolve direto, sem precisar ir nos Ajustes.)

Instalar no Windows

  1. Abra o arquivo .exe baixado.
  2. Só na primeira vez: o Windows Defender pode avisar "O Windows protegeu o computador" (o app não tem certificado pago). Clique em Mais informações → Executar assim mesmo.
  3. Siga o instalador — ele cria um atalho e abre o app sozinho no final.
Controle e Convidado continuam abrindo no navegador normal, como sempre.
